# Billal Abulfotuh — Engineering Portfolio

Static electrical engineering portfolio for https://billala123.github.io/.

## Editing

- `index.html`: semantic page content, project links, and metadata.
- `styles.css`: layout and responsive styles.
- `script.js`: optional current-year enhancement; all content and navigation work without JavaScript.
- `assets/`: optimized WebP copies of actual images from the project repositories.
- `asset-sources.json`: original repository and path for every image.

Project descriptions are sourced from each linked repository README. The Custom Phone is explicitly ongoing. No measured radar accuracy, range, or finished firmware is asserted. The site does not claim an institution, graduation date, or unverified professional experience.

## Preview

Serve this directory with any static HTTP server, for example `python -m http.server 4173`, then open http://localhost:4173/.

## GitHub Pages

Publish from the `main` branch and repository root (`/`) in Settings → Pages. The `.nojekyll` file enables direct static serving. No framework, dependencies, or build step is required.
